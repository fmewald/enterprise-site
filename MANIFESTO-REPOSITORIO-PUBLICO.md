# Manifesto do repositório público

## Pacote correto para o GitHub

Utilize exclusivamente:

`enterprise-site-PRE-LANCAMENTO-INTEGRAL-V1.2-REPOSITORIO-PUBLICO.zip`

Ele contém o código-fonte necessário, páginas, templates, artigos, CMS, assets, build, dependências declaradas, testes técnicos, configuração da Netlify, README, este manifesto e o `dist/` de homologação.

## Conteúdo mantido fora do GitHub

O pacote público não contém:

- auditorias estratégicas;
- relatórios internos;
- checklists administrativos;
- pendências privadas;
- logs e resultados detalhados;
- mapas internos;
- arquivos temporários;
- credenciais, tokens ou dados de usuários administrativos.

Esses materiais ficam somente em:

`enterprise-site-PRE-LANCAMENTO-INTEGRAL-V1.2-AUDITORIA-INTERNA.zip`

## Motivo dos dois pacotes

O repositório `fmewald/enterprise-site` é público. A separação reduz a exposição de documentação administrativa sem retirar do GitHub o código necessário para build, CMS, testes e publicação.

## Regra de segurança

Nunca envie ao GitHub senhas, tokens, chaves privadas, capturas do painel, lista de usuários do Identity ou e-mails pessoais de administradores.
